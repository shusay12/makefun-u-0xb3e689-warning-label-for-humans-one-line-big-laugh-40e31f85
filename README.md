An entry for the make.fun bounty [Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85).

Running `main.py` (Python 3.13, standard library only, no network) writes
one original warning-label line (154 characters) to `/output/entry.txt`:

> WARNING: This unit runs on caffeine and spite, replays its most
> embarrassing moment from 2009 at 3 a.m., and will insist it is fine
> while visibly on fire.

Three recognisable human flaws stacked in deadpan warning-label language:
a body that runs on caffeine and spite instead of fuel, a brain that
replays one embarrassing moment from 2009 every night at 3 a.m., and the
reflex to insist "I'm fine" while visibly on fire. It reads like a real
safety label for a defective product — except the product is every human
being. It runs identically every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
